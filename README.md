# pd_validacaoModelosClusterizacao
PD feito para a matéria de Validação de Modelos de Clusterização

Neste projeto, utilizei dados sobre frutas, para criar um modelo de agrupamento das mesmas, visando a auxiliar um projeto de compras de frutas pelo nutricionista, de acordo com similaridade entre elas.
Nele utilizamos o K-means e o DBScan para determinar as melhores maneiras de se agrupar essas frutas
O k-means dividiu as frutas em 2 clusters e o DBScan também
De modo geral, os clusters levaram em conta o tamanho e o peso das frutas (o DBScan levou em conta também o valor)

Para rodar em seu ambiente, baixe os arquivos, crie um ambiente virtual usando conda (https://conda.org/) e instale as versões de bibliotecas citadas no requirements.txt, em seguida, rode o notebook neste ambiente virtual criado por você
